Idea to Outline

A free, browser-based tool that helps fanfiction writers turn a scene idea into a structured outline.

Try it live: https://idea-to-outline.vercel.app

What it does

You answer a short sequence of guided questions about one scene: who is in it, what each character wants, what is standing in their way, where the scene turns and where it lands. The tool then arranges your own answers into a labeled outline (Setup, Tension, Turn, Resolution) and asks you to check the result against the goal you set for the scene.

It is a cheat sheet for an idea you already have. It does not write your scene and it does not invent plot for you.

Privacy
Everything runs in your browser.
What you type is never sent anywhere, saved or logged.
There is no AI involved when you use the tool. Your answers are slotted into a fixed template by plain JavaScript.
How it was built

This is a portfolio project, planned, built, promoted and measured end to end:

Planned and tracked in Trello, with a build log for every work session
Built as a single static HTML, CSS and JavaScript file
Hosted on Vercel, with GitHub as the code home
Designed for the fanfiction community I write in, starting with Outer Banks fandom

I used an AI assistant as a coding and drafting aid during the build. The question design, scope decisions and copy decisions are mine. The assistant is not part of the tool itself.

Scope

The tool currently covers scenes with two central characters. Solo scenes and larger group scenes are planned as future improvements.
